Entry for the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) on make.fun — one original one-line office joke, judged by an AI comedy-club judge.

## The joke

> My performance review called me "a self-starter," which is HR for "you do the work of three people, so we complimented you instead of hiring two."

146 characters, one line, about office life.

## How it works

`main.ts` (Node 22) writes the joke to `/output/entry.txt`. That is the whole program — the entry is the line itself.

```bash
node main.ts
cat /output/entry.txt
```
